Part IX

Running it, and the map of the code

Commands, file-by-file responsibilities, the constants that matter, and everything currently known to be unfinished.

52 · The commands

a new run, end to end 
# 0. the hits chain first — its alignment and event cache are inputs to
#    the calibration stage, and its hits are the seeds
mx_june_cosmic_qa/03_alignment_and_tpc.py <key> --refit --veto=50

# 1. calibrate. Pin what has been measured; fit only the rest (§35.1)
python -m wft.calibrate <key> --jobs 12 --share-mode lp \
       --fix-hyper "c1=0.25,c2=0.10" --fix-v 34.0

# 2. reconstruct into a parquet table
python -m wft.cli reco <key> --matched-only --jobs 12

# 3. downstream
mx_june_wft/01_alignment.py <key>
mx_june_wft/02_efficiency.py <key> --max-dropped -1
mx_june_wft/03_angles.py <key>          # CHECK THE IMPLIED-V SPREAD
mx_june_wft/04_maps.py <key>
mx_june_wft/digest.py <key>

# the kernel cross-check — model-free, needs only waveforms
mx_june_wft/05_beam_kernel_xcheck.py <key> --tan-max 0.06
importing an existing calibration 
python -m wft.cli bundle <key> --from-legacy <dir> --hyper-file hyper_v2.json
python -m wft.cli info   <table.parquet>

55 · Open items

Collected from throughout, roughly in order of expected value.

Open · reconstruction
  1. Widen or re-centre the p₀ scan (§21.1). 21 % of planes start outside the box and carry 5× the catastrophic-failure rate. Cheap to try, measurable immediately.
  2. A scale-free candidate score (§27). Δχ² per dof, or a likelihood ratio on a common window, instead of raw Δχ² across windows of different size.
  3. A track-compatibility seeder. The right cluster is among the candidates 95 % of the time and the current rule finds it 55 % of the time.
  4. Per-plane tau_s (§14.3). det3's Y-view copy arrives ~2× later than its X-view copy and an amplitude-only kY cannot express that.
  5. A/B the pair selector (§28) across the fleet and switch it on if it wins.
  6. Saturation recovery rather than censoring.
Open · calibration
  1. Rebuild det2, det6 and det7 with the measured-kernel recipe. Their bundles were lost and their old ones were degenerate anyway.
  2. Loosen the template cuts for low-gain chambers (§34) before touching their kernels again.
  3. det3 and the rest of the fleet on share_lp — only det4 has been recalibrated under the new kernel form.
  4. An independent humidity handle. |v| to better than ~1 µm/ns is currently degenerate with the water fraction.
Open · physics and hardware
  1. The X-view sharing asymmetry (§51.1) — same sign in three independent datasets, mechanism unknown, and it contaminates a tilt measurement.
  2. A mechanical flatness check whenever a chamber is next open, to confirm the in-situ column maps.
  3. Port the remaining v(E) and gap-map scripts into the packaged chain; they still live as R&D scripts.
  4. Time resolution is still on the hits basis; the port is pending.

56 · Glossary

p₀track position at the mesh, mm. The primary position output.
wtransverse speed of the charge column, mm/ns. The primary angle output.
t₀arrival time of the charge liberated at the mesh, ns.
udrift time since t₀, ns. The model's depth coordinate.
zdrift depth, mm. z = v·u.
qkcharge in depth bin k, non-negative, solved by NNLS.
Fikfraction of bin k's charge landing on strip i.
h(t)measured impulse response of one plane's electronics.
kernelthe resistive charge-sharing transfer function: c1, c2, tau_s, sigma_s, kY.
ladderthe old estimator: one time per strip, a line through (position, time).
compressionthe ladder reading ~15 % shallower in time and therefore too steep in space.
implied vw / tan θ_ref. Must be flat against angle.
ref-pinneda fit with the geometry fixed to the M3 reference and only the response free.
bundlea per-detector, per-condition calibration directory.
CNScommon-mode noise subtraction, per 64-channel Dream block.
M3the external reference telescope. Recipe: χ² < 1.0 and NClus = 4.
ftstthe FEU fine timestamp, 10 ns units, used to classify the inter-FEU offset.
NNLSnon-negative least squares.
