What this does not rule out

  • Which k is right is not settled by the wall: it is coarse, and prefers the pilot only mildly. The A–C cosmic truth (is2 closes to ~0.97) is the stronger argument.
  • The same-track test only covers tracks both chains find in the same place; it says nothing about the tracks only the pilot finds.
  • Production lacks k for several run/arms; the ratios skip them, so they cover 27 of 36 runs per arm.
  • The cosmic truth stops near |tan| 0.5; nothing here tests 0.5–1 on data except the wall confirmation.
  • Wall confirmation is a purity proxy with its own angle-dependent extrapolation error.
  • Only the first sub-run of each run; within-run variation is untested.
