Notes

  • Each cell is one strip (0.78 mm) × one 60 ns sample, pedestal and common mode subtracted, exactly what the paper's displays draw. With "true picture" on, 1 mm across the strips and 1 mm of drift print the same length.
  • Fits are from the first reconstruction pass (the copy on the desktop). The paper's figures use the two-track re-pass, so second-track fits and candidates can differ slightly from the paper's. The data cells and reference tracks are identical.
  • "Model" and "residual" exist only for the single muon (event 7884), in a narrow window around the track.
  • The "3D box" mode draws the two views on the back walls of the drift volume. The 3D lines are the reference track and the first fitted track (X and Y fits paired).
  • Canvas text uses browser fonts. The paper version will use the document's fonts.
