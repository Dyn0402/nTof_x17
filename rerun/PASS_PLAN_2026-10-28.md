## 2 · Engineering for tonight (E1–E5), then a dry run

**E1 · `rerun/calib/make_bundle.py`: a bundle from nothing.** Inputs:
- the calibration cache;
- the measured templates (`wft.calibrate.measure_templates`, one X-derived template, `rc_tmpl='x'`);
- the measured latency (`measure_latency` → `t0_abs_from_latency`, pinned σ 0.05);
- `physics_inputs.json` (σ0, Dp, D_rc,y for det4, v);
- the registry K, the one-rule dead/hot masks (`fe_unify2/masks/bench_det*.json`, after F7);
- unit gains, no bow, no w0/kw.

It writes provenance naming every input. `check_kernel_ordering` / `check_xy_pairing` still run at save.

**E2 · `rerun/calib/bow_node.py`.** A DAG node for FB's `set_bow`. It reads a reco table, its waveform alignment, the
03 angles and the row's v2 M3 rays from EOS. It joins them as `ws_v_w0/build_table` does and writes `bow_block_<det>.json`
next to the table. Today `set_bow` only reads the laptop mirror (`fbcommon.load`).

**E3 · `make_pass_dag.py calib` phase + the W0KW fix.** Per golden calibration row (det2 o22_long_det2, det3 sat_det3,
det4 g_det4, det6 g_det6_long, det7 g_det7_long), into a **new EOS analysis root `Analysis_pass1`**, so that no old
product can be picked up:

| step | nodes | what it makes |
|---|---|---|
| CAL0 bootstrap | HITS → CACHE0 (hits-chain alignment: the corridor only, never a constant) | waveform cache 0 |
| CAL1 bundle 0 | TMPL0 (templates + latency) → DRC0 (det2/3/6/7: `recal.py --free rc_D_y`, σ0/Dp/v fixed, p0 profiled ±2 mm) → MAKE0 (E1) | bundle_0 |
| CAL2 bundle 1 | RECO1 (8000 matched) → ALIGN1 (waveform) → CACHE1 (`build_cache_wft.py --align`) → TMPL1 → DRC1 → MAKE1 | bundle_1 (convergence check against bundle_0) |
| CAL3 angles + bow | RECO2 → ALIGN2 → ANG2 → W0KW2 (`set_w0kw --table --angles --sigma0 0.30,0.30`) → BOW2 (E2) → W0KW2b (`--bow-json --table`) | bundle_2 |
| CAL4 final | RECO3 → ALIGN3 → ANG3 → W0KW3 (`--table --angles --bow-json`) | **`calib_bundle`** (convergence check against bundle_2) |

Two more parts of E3:
- **Every** W0KW node in finalize/vrefit/pass gets `--table {out}/wft/events.parquet` (F5/F11). Without it, dt_xy and
  pairing go stale, and the node aborts on a bow bundle (set_w0kw.py:95–97).
- vrefit `--keep-v` keeps the golden bundle's bow block. The bow is a chamber property, so it is not refit per row.

**Convergence criteria.** These are written to `CALIB_CONVERGENCE.json` per chamber:
- template shape: L2 difference below 1 % of the peak;
- latency C within 2 ns;
- D_rc,y within 5 %;
- w0 within 0.02 µm/ns and kw within 0.5 %;
- bow terms within 1σ;
- alignment within 0.1 mm / 0.05°.

A chamber that does not converge gets one more iteration, and the overrun is written down.

**E4 · SPS phase.** `make_pass_dag.py sps` builds one node per `sps_registry.csv` row (71) running `sps_stage.sh` /
