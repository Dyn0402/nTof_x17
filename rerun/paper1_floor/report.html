Verdict. See README.md for the full statement. The unexplained term is not the reference (no M3-chi2 dependence), not a per-event common cause (X-Y |r| < 0.1), not position structure finer than the tilt map and not the X copy (Y has it too). Event conditions the toy does not generate (saturated planes, the bright tail, topology) are 12-37 % of it (65-92 % on det7). The rest, 0.56-0.63 deg on det2/3/7 X (1.42 det4), is present on clean events, roughly angle-independent, and fit-visible: a best-chi2 selection removes the same share of it as of the toy's own error, so it behaves like an under-modelled stochastic part of the waveform (the data chi2/dof is 4-15x the toy's and grows as Q^1.4-2), not like the chi2-blind geometry the 10-27 study proposed. The bench position resolution agrees with SPS once M3's own scattering is measured.

What this does not rule out

  • The angle-independent remainder is not identified; it is bounded, not explained.
  • The Y toy uses the X generation (no measured Y tails).
  • The bench chamber position rests on the M3 pointing P (±10 % moves the near-normal chamber value by ~±50 µm) and on a linear sigma²(chi2).
  • det6 (92 % saturated) has no representative toy-like sample.
