## 0. The one-line result

```
t_flash_at_detector(bunch)  =  tof_PKUP(bunch)  +  C[detector]
```

with `C` measured per channel on the seven runs in which the SiPM-wall blanking
gate was disabled. `C ≈ −1715 ns` for every wall channel. **Do not use the PSA's
stored `tflash`** — see §6.

## 1. Why this needed a special run

In normal running the SiPM wall signal is diverted around the γ-flash (a ~1 µs
blanking gate, driven by N1081B module 6 section C). The walls therefore never
record the flash itself: the PSA's flash finder locks onto either the blanking
gate transient (≈0.3–1.2 µs *before* the real flash, depending on epoch) or a
clamped leak at roughly the true flash time — and it switches between the two
from bunch to bunch. That bistability is the origin of the ~350 ns
cross-detector offsets in `../flash_calibration.json`.

Seven runs escaped the gate. They are the only place in the campaign where the
true flash arrival time is directly observable in the walls.
