# Fine Magboltz (water, air) grids — 2026-10-31

**Verdict.**
- **The SPS grids are fine enough.** On both CF₄ (`beam`) and CO₂ (`co2`), as extended for the gas fit, linear interpolation moves a fitted composition by
  - ≤ 0.01 % water;
  - ≤ 10–25 ppm O₂ at the drop-one test's doubled step, so a few ppm at the real step;
  - in field, ≤ 0.2 % in v.

  The η errors are at Magboltz's own noise level (4–8 % per point, which `GasGrid` smooths in log E). A finer SPS grid would not change the gas fit. The 24 midpoint points below check this directly.
- **The bench grid was not fine enough.** `bench`: Ar/iso 95/5, water 0/0.1/0.2/0.4/0.7/1.0 %, 12 fields.
  - At its own steps, interpolation is off by 1–5 % in v below 150 V/cm, in both water and field. Linear-in-water misses v(E) by up to 18 % at the 0.4 % node when the step is doubled.
  - It stops at 1 % water, while det6's slow 6-26 night (17 µm/ns at 243 V/cm) needs about 1.3 %.
  - It lacks the measured fields 312/333/367/382 V/cm.

  A fine bench cube was submitted (2442 jobs).

## The test (`mb_interp_test.py`, `results/mb_interp_test.json`)

**Method.**
- Drop each interior water node (and each air node) of each gas. Rebuild `GasGrid` without it, predict v, η, D_L and D_T there, and compare with the real point.
- Translate each error into the shift a fit would make: δv/(∂v/∂w) as water, δη/(∂η/∂a) as O₂.
- Linear-interpolation error ∝ step², so the real grid's midpoint error is about ¼ of the drop-one error. That holds where the error is curvature and not Magboltz noise; where it is noise it doesn't shrink.
- The field axis was tested the same way, inline.

| gas | axis | drop-one (doubled) step | v error, median / max | water-equivalent (p90) | O₂-equivalent (p90) |
|---|---|---|---|---|---|
| beam | water | 0.10–0.20 % | 0.1–0.5 / ≤ 0.6 % | ≤ 0.008 % | ≤ 15 ppm |
| beam | air | 0.02–0.06 % | ≤ 0.05 % | — | 8–14 ppm |
| beam | field | 25–75 V/cm | 0.1–0.55 / ≤ 0.7 % | | |
| co2 | water | 0.40 % | 0.8–1.8 / ≤ 2.1 % | ≤ 0.03 % | 12–20 ppm |
| co2 | air | 0.10 % | ≤ 0.07 % | — | 11–24 ppm |
| co2 | field | 43–50 V/cm | 0.4–0.7 / ≤ 1.2 % | | |

Magboltz η noise per point, as the rms of raw log η about its smooth curve: beam 6 %, co2 4 %, bench 8 %. The η drop-one errors, 2–5 %, sit at that floor.
